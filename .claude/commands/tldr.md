# /tldr

Review recent session notes and promote durable knowledge.

## Read

- CLAUDE.md
- history.md
- architecture.md
- recent session notes

## Promote only durable knowledge

Examples:

- tuned gains
- hardware discoveries
- architecture lessons
- best practices
- recurring debugging patterns
- confirmed or disproven hypotheses

Update the appropriate Obsidian topic notes.

Do not copy temporary task status, blockers, or session chatter.

If multiple sessions reached the same conclusion, consolidate them into one clean knowledge entry.

Finish by reporting:

- vault notes updated
- new long-term knowledge captured
- duplicate/outdated information removed
