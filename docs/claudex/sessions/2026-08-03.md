# 2026-08-03 — Competition PathPlanner replacement and pilot validation

## Context

The `src/main/deploy/pathplanner` contents were replaced with the autos used during competition.
The current working tree contains uncommitted PathPlanner changes across the autos, paths, and
PathPlanner settings; no Java production code was changed during this session.

The team primarily used the autos in the `Simple Autos` folder. `LT Neutral` and `RT Neutral` are
the pilot routes for evaluating whether the drivetrain can follow straighter paths without using
curvature and speed reduction as a competition workaround.

## Current pilot definitions

- `LT Neutral.auto` remains in `Simple Autos` and runs `Left Trench Start`, `Left Trench Neutral`,
  `Left Trench End`, then the existing 7-second deadline group containing `Orbit` and `Shooting Sequence`.
- `RT Neutral.auto` is the right-side trench-to-neutral-zone pilot. It currently runs `Right Trench
  Start`, then the same 7-second Orbit/shooting deadline group. The current RT auto does not contain
  a separate neutral path; `Right Trench Start` is the path into the neutral ball-pit zone.
- The deadline command group was retained. `Orbit` is bounded to 2 seconds and `Shooting Sequence`
  to 5 seconds, so the 7-second deadline prevents an autonomous hang while leaving a timing buffer.

## Simulation validation

Using the WPILib JDK 17 and the existing targeted regression harness, five fresh runs were made for
each pilot under the standard 15-second cap.

### RT Neutral

- 5/5 runs completed naturally; no stall or tracking assertion failed.
- Runtime was approximately 14.48 seconds, leaving approximately 0.52 seconds of simulated reserve.
- Maximum lateral error ranged from 0.059 to 0.066 m.
- Maximum longitudinal error ranged from 0.151 to 0.160 m.
- Path timing was repeatable: the path-following window ended at approximately 7.48 seconds in
  each run.

### LT Neutral

- 5/5 runs were reported as completed by the harness; no stall or tracking assertion failed.
- The route is effectively at the 15-second boundary, with no meaningful reserve. Logs reached about
  15.0 seconds and the path-following portion ended at approximately 8.02 seconds before the 7-second
  Orbit/shooting deadline.
- Maximum lateral error ranged from 0.099 to 0.119 m.
- Maximum longitudinal error ranged from 0.271 to 0.289 m.

The targeted tests returned nonzero status only because the checked-in goldens still record
`completed=false`; the current runs produced `completed=true`. No golden was re-recorded.

## Interpretation and next steps

RT Neutral is the stronger first hardware pilot: it has repeatable simulation tracking and about
half a second of simulated timing reserve. Test it on the real robot at reduced speed first, with a
spotter and measured clearance near the trench and neutral-zone elements, then repeat at intended
competition speed.

LT Neutral is promising but timing-borderline. Do not call it competition-ready until its timing
margin is understood. First measure how much of the 7-second shooting deadline is actually needed;
only then consider creating margin by an explicitly approved timing or path change.

Simulation evidence does not prove physical clearance. Real-robot validation must account for the
bumper footprint, wheel slip, battery voltage, calibration, and localization error. Do not update
the goldens or commit the replacement PathPlanner set until the pilot behavior and intended timing
are approved.
