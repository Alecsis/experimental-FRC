# Session Notes

One file per session: `YYYY-MM-DD.md` (append a new `##` section if more than one session happens the same day — don't overwrite).

Written by `/recap`. Read by `/bootstrap` (latest note + its `## Handoff` section only — not the whole history) and, on a weekly cadence, by `/tldr` for vault promotion.

Each note ends with a `## Handoff` block (current state, verified facts, unverified items, next safe action, things not to change) — that block is what the next session actually needs, not the full body above it.
