## Why it changed

The `claude.md` cut from 152,379 bytes to 4,820 was a real win (that file loads every session, and
the old one carried single lines of 24,446 and 8,825 characters). But it deleted
`C:\Users\xdm\6767 frc bible` / `00 Index.md`, and `grep` confirmed the string existed **nowhere
else in the repository** — leaving `/tldr` documented as having a job with no recorded target.
Directory and index file were confirmed present on disk before the path was written back.

The `close()` note matters because `RobotContainer.drivetrain` is `public static`, initialized once
at class-load. A second `Robot` in the same JVM reuses the *closed* instance: the MapleSim notifier
is stopped and nulled, physics never advances, and motion assertions go silently vacuous rather than
failing. Nothing hits this today — `forkEvery = 1` plus the existing one-Robot-boot-per-class
convention (`AutonomousHealthMonitorTest` has 15 tests and builds a Robot in exactly one) — but
closing a static made that convention load-bearing for the drivetrain, which was undocumented.
